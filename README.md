# 🃏 Pair-Game

Jeu de paires (memory) en HTML, CSS et JavaScript pur.

## Fonctionnalités
- 4 niveaux : Facile, Moyen, Difficile, Extrême
- Compteur de coups et chronomètre
- Record sauvegardé pour chaque niveau
- Compatible mobile et ordinateur, mode sombre

## Lancer le jeu
Ouvre simplement `index.html` dans ton navigateur.
